## 3. 凭什么说它是好的（本工程的「母题」）

一句话：**任何「✔」都必须配一次「把它改坏、看它是否真的变红」**，否则不算数。

- **判据（20 组）**：Node 客户端验证 + 精灵渲染纯函数 + 二进制帧协议 + Python 端到端 +
  跨实现一致性 + 发布演练 + 静态检查 + **协议三列一致性** + **DrawCmd 逐顶点一致性** +
  规模并发 + 计划数字核对 + 宿主回归 + 06 三件套 + 停帧看门狗 + 模型版本指纹 + 模块级单测。
- **两条「跨实现守卫」**（P43）：`server.py ∪ client.html = protocol.md` 三列独立提取后必须相等；
  离线渲染器与实时渲染器**逐符号逐顶点**比 `xy`/`uv`/矩阵（4 build / 57 QUAD）。
  两条都先证明"会红"再报绿 —— 各带 6 / 7 条反向测试。
- **两份变异测试**（`①d` 客户端、`②f` 服务端/引擎）：把实现故意改坏，逐条确认**对应判据真的会红**；
  每条连续跑两遍（只红一次算抖，不算数）。
- **机械核对**：`tools/verify_plan.py` 把「计划里的可机器验证数字」和「README / 发布检查单里的数字」
  与实跑对照；`06` 侧还有 `audit_fixes` / `audit_doc_numbers` / `verify_report` 三件套。
- **本次长时任务新增的机械守卫**：客户端变异测试 13 条、服务端/引擎变异测试 13 条、
  静态未定义名检查、发布演练 7 条（含「停服先存后杀」「会话身份挺过真重启」）、
  文档数字核对（含「Lua 续行取模误用」规则）。

## 4. 如实登记的缺口（不藏）

| 缺口 | 状态 |
|---|---|
| **战斗只有单向：生物不会反击** | P61 实测：spider 被连打 10 下（100→0 血）**全程没还手**，玩家血量 150 一点没掉。攻击链路本身是通的（`GetAttacked` ← `DoAttack`），缺的是**仇恨/反击那一层**（brain 的 targetfn 没锁定玩家）。⇒ 现在是「玩家单方面清场」，不是对等战斗。未查根因，未排期 |
| **编辑器只做到「最小可用」** | P62 有：层级 / 属性 / 工具栏 / 点选 / 拖动移动 / 生成 / 删除 / 存档。**没有**：撤销重做、多选、复制粘贴、变换手柄、Prefab 编辑模式。另外 `/editor/*` **只接受回环来源** —— 从别的机器开这个页面，面板能显示但每个操作都 403（这是设计：编辑器能删对象/挪玩家，不该和运维通道共用开关） |
| **增量帧没做** | 实测每帧变化率 55%，收益抵不上「增删跟踪 + 关键帧重同步」的复杂度（判据 `S4` 记着那个数）。改主意前先看那个数 |
| `§9v.5`「某种客户端节奏让模拟循环停住」 | **未复现**（`repro_v5.py` 3 轮 × 2 模式 6 次，「猛发 targets + 紧读」下 tick 稳 24~32/s）。**不当已修** |
| 光照代理是**代理不是等价** | 营火之外只认「按**槽位**登记的随身光源」（P38）；**不模拟**「燃料烧完 / 被雨浇灭」；默认关 |
| 06 侧两处光照桩互相矛盾 | **登记不在 06 修**（那是保真基线） |
| 发布形态 | **已定案（P61）**：形态 A（本机 / 内网）**采纳**，默认绑 `127.0.0.1`（判据 `U45` 守着，改成 `0.0.0.0` 必红）；形态 B（公网）**暂不执行** —— 需一台能跑 `Python 3.13 + lupa` 的机器，本机不具备。⇒ **目前没有可分享的公网链接**，也不假装有 |
| `--allow-debug` | **公网部署必须关**（否则任何人可 `/debug/kill` 杀角色）；默认关，返回 404 即未开 |
| 「自己什么状态」只有数字，没有解释 | 饿到 0 会怎样、理智怎么掉 —— 引擎侧在算，但**没有引导**；属于玩法深度，未排期 |
| 声音**只有账、没有声** | `Sim.Audio` 能证明「谁在什么时候要放什么音」，但宿主没有混音后端 ⇒ 判据只验记账，**不验响不响**（P41 登记） |
| 农业链起点不是「播种动作」 | `PlantSeed` 要玩家 `ACTIONS.PLANT`，headless 无入口 ⇒ `mech.lua` 从 `SpawnPrefab` 起步，只覆盖生长→收获（P41 登记） |
| `weather` 组件仍加载不上 | **Lua 5.1/LuaJIT 的 60 upvalue 硬上限**；实测 5.2+ 可编译、LuaJIT 不行。换运行时才解，改宿主解不了（P41 已把结论+复现命令落盘） |
| 原点堆着一坨「死重量」 | 约 140 个 `*_classified` 镜像实体因**宿主不做父子跟随**，坐标**全停在 (0,0)**（`M.snapshot` 已按「有没有 build」把它们过滤掉，但 `act_targets` 仍会扫到）。它们不会成为目标（`action_for` 为 nil），但占据了索引里原点那一格 ⇒ 每次查询多扫 140 个、且让「扫描量占比」类判据失效。**P41 登记，未改**（改法要么补父子跟随，要么在索引建桶时按 build 过滤，后者会动行为，需先有更强的等价判据） |

## 5. 最近一轮做了什么

**P62：编辑器界面（2026-10-21 深夜）**
- 用户截图反馈「页面只有一张地图，没有任何可操作界面」。查证分两半：
  **左侧那片黑不是 bug** —— 世界是 128×128 圆形岛，玩家在岛边时屏幕一侧对应
  **世界之外的负坐标**，那里没有地形，露出 `#0d1117` 底色（`地形=128x128` 与缩放两个数能印证）。
  **但「只有视口、没有编辑器」是真的。**
- 补上对照 Unity 的四件最基础的事：**层级列表 / 属性面板 / 工具栏 / 视口选中与编辑**。
  F1 开关；`#ed` 是穿透层，打开编辑器时中间地图照样可点可拖。
- 后端新增 `/editor/entities|move|remove|spawn`。门槛**另立**（`_editor_allowed`）：
  看**本次请求的 peer 是不是回环**，不看 `--allow-debug` —— 运维通道与本机工具是两个诉求，
  共用一个开关会互相绑死。**玩家实体拒绝删除**（会破坏 key→角色 映射）。
- 「点击 vs 拖动」**只在 `ptUp` 一处判定**（6px 阈值）：按下只记账。反过来会让
  **每次拖地图都顺手选中一个对象** —— 而拖地图正是编辑时最常用的动作。
- 判据 `E14`（每步**回读**；`count` 与 `listed` 分开断言；`/debug/*` 必须仍 404 ——
  这两套门槛没被合并的现场证据）+ `U46`（回环 4 种写法放行 / 外网 5 种拒绝 / 缺地址拒绝）。
  两条变异都实测变红：`_editor_allowed` 改成 `return True` ⇒ 「非回环来源被放行了：'8.8.8.8'」；
  摘掉玩家保护 ⇒ 「玩家实体 #4 被删掉了」。
