## 目标

**验证核心假设：DST 原版 Lua 脚本能否在「契约复刻版」引擎上不改一行运行。**

这不是仿写一个游戏，而是做一个**忠实实现引擎 API 契约的宿主**。
一旦成立，收益是：4030 个原版 Lua 文件（1.5M 行）成为可运行、可自由修改的资产。

---

## 为什么是这个目标

已查明的事实：
- 引擎对 Lua 暴露的接口总共 **669 个方法**（`TheSim` 194 / `TheNet` 184 / `Widget` 269 / `Screen` 505 / `EntityScript` 142 / `Transform` 36 …）
- Lua 层**自包含**：819 个 `require` 全是内部 Lua 路径，零外部 C 模块
- `03-参考架构/` 6248 行已证明「纯 Lua 复刻 DST 架构」可行
- `class.lua` 零引擎依赖，可直接复用真实版
- `scheduler.lua` 只依赖 `TheSim:ProfilerPush/Pop`，可直接复用

## 风险

| 风险 | 应对 |
|---|---|
| 某个组件耦合太深，加载不动 | 写桩，记入 GAPS.md，保证主链贯通 |
| TUNING 数据不全 | 从 `05-数据/数值参数总表` 提取，或用合理默认值 |
| `standardcomponents.lua` 依赖爆炸 | 先只加载需要的函数，用沙箱隔离 |
| 时间不够 | 保 Phase 1-3，Phase 4-6 顺延 |
