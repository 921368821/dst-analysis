## 09:3x 第三十七轮：07 的 P21（会话身份 / 刷新不丢角色）

**要解决的问题**：P20 之后，客户端**刷新一次页面就丢掉自己的角色** ——
重连拿到一个新 wilson，站在原地的成了**没人控制的空壳**，而且每刷新一次多一个。

**做法**：浏览器 localStorage 存随机 key → 连 WS 时带上（`/ws?bin=1&key=…`）；
服务端 `by_key` + `reserved[slot]=到期时间`（宽限期默认 60 s）⇒ 同 key 重连**复用原槽位**
（同 guid、同位置）；到期没回来才真删。同 key 二次连接 → **明确拒绝**（`busy`）而不是抢身体。

**★★★ 一路踩出来的四个坑（都值得记住）**：
1. **`const` 的 TDZ**：`const SKEY` 落在了 `connect()` **之后** ⇒ "Cannot access 'SKEY' before
   initialization"。**与 Lua 的 `local` 只对它之后的代码可见是同一个坑**（那边用前向声明解）。
2. **沙箱又少一样东西**：Node 沙箱没有 `localStorage` ⇒ 客户端那句被 try/catch 吃掉 ⇒
   SKEY 恒为 '' ⇒ **测试永远走不到「带 key」那条路**。（第 5 次同款：location.search /
   XHR+Image / createElement+drawImage / localStorage）
3. **`pcall` 又吞了一次错**：`pcall(spawn_wilson_at)` **漏了参数** ⇒ 函数里 `nth-1` 对 nil
   做算术 ⇒ 被吞 ⇒ 返回 false ⇒ 症状「宽限期后重连没拿到角色」。靠 D2 抓到。
4. **槽位 0 的「永久豁免」是错的**：它也可能被带 key 的客户端认领，那时就该有生命周期
   （否则刷新一次漏一个空壳 = D2 抓到的）。改成「匿名连接才享受永久豁免」——
   **向后兼容只保留在「没身份」那条路上**。

## 10:3x 第三十八轮：07 的 P22（**交互**：世界终于能碰了）+ 一个未解问题

**之前的状态**：从 P1 到 P21 玩家**只能移动**，世界里的一切都碰不到 —— 「有世界、有角色、没交互」。

**先探明**（原版动作链在宿主里通不通）：`ACTIONS`/`BufferedAction`/`Pathfinder` **都在** ✓；
evergreen 有 `workable`（`workleft=15`，`action.id="CHOP"`）；`PushAction` **真的砍得动** ✓；
**但超出作用范围（≥2 格）时不报错也不做事 —— 静默无效** ⇒ 必须自己补「距离判定 + 走过去」。

**设计**：目标由**服务端**挑（客户端只有帧里的 id/位置/名字，算不出「能不能砍」——
那套规则只在引擎里；让客户端猜 = **规则复制**，两边迟早对不上，本工程已栽过两次）；
客户端取**最近**那个、画圈、按空格发 `{cmd:"act",v:id}`（按住每 0.7 s 重发 = 连续砍）；
服务端 `act` 里判距离，太远就**记下待做动作并朝它走过去**，到了再 `PushAction`。

**判据**：E1（进程内：找到目标 → 走过去 6.8 格 → workleft 5→1 + 三种拒绝都带原因）、
C6（跨进程：拉 12 个目标 → act_ok 增加 → 坏 guid 被拒并记原因）、客户端 ×2（无目标不发 / 按下只发一条 / 0.7 s 后重发 / 松开发 unact / targets 不是快照）。

### ⚠️ 未解问题：某种客户端节奏会让**模拟循环停住**（如实登记，不装作已修）

**现象**：客户端连上后**连续发 `targets` + 紧循环读帧** ⇒ 服务端 tick 几乎不涨（6 秒只涨 1）。
换成「持续读线程 + 定时发送」（真实客户端的做法）就完全正常。
**已定位**：二分到 `targets` 分支里的 `self._send(...)`（跳过它就正常）；
`faulthandler` 显示模拟线程**活着**且停在 `time.sleep(0.033)`；**加一行 print 就复现不了**（时序相关）。
**已排除**：嵌套加锁 / `_send` 在锁里 / `sys.exit` / 超长 sleep（加了守卫从未触发）。
**处置**：判据改成真实节奏；补三处**永久诊断**（`handle_error` 打栈、`RT_DBG_WS=1` 打收帧/退出原因、
「这一拍睡 >0.5 s 就报警」）；**登记为未解**（根因未定 + 复现条件 + 已排除项）。

### ★★ 这一轮最大的教训：**heredoc 里的 assert 失败 = 整批编辑静默丢失**
